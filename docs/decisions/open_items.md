# Реестр открытых решений владельца

**Дата среза:** 2026-11-12 · **Связанные документы:** [Журнал ADR](README.md)

Реестр фиксирует вопросы, которые нельзя закрыть архитектурным решением или кодом: ответ даёт только
владелец проекта. Для каждого пункта указано, почему он открыт, что блокирует и к какому этапу ADD §22
должен быть закрыт. Пункт не считается решённым, пока владелец явно не зафиксировал ответ; отсутствие
ответа не заменяется допущением по умолчанию.

| ID | Формулировка | Почему открыт | Кто решает | Что блокирует | Когда решить |
|---|---|---|---|---|---|
| `OI-001` | Точное имя и протокол API внешнего LLM-агрегатора | Записан только кандидат «ранее использованный агрегатор»; имя, endpoint и протокол не задокументированы и не должны выдумываться | Владелец проекта — решение владельца | Реальный адаптер Model Gateway (ADR-005); без него нет реальных вызовов модели | До выхода из Итерации 1; окончательно — до extraction в Итерации 3 |
| `OI-002` | Подтверждённые capability выбранной модели: structured output / JSON Schema, tool calling, streaming, поведение reasoning-блоков | Capability известны только по типам DTO, а не по измерениям на endpoint; без них нельзя выбрать путь извлечения | Владелец проекта — решение владельца | Структурированный extraction path и разбор ответа; `require_structured_output()` нечем обосновать | До начала структурированного извлечения, Итерация 1–3 |
| `OI-003` | Подтверждённые лимиты контекста, максимальной длины вывода и rate limits выбранной модели | Числа в `ModelCapabilities` — контрактные значения по умолчанию, а не фактические; бюджет считается по ним | Владелец проекта — решение владельца | Детерминированная политика retrieval-режима и расчёт контекстного бюджета (ADR-007) | До реализации политики выбора режима, Итерация 4; лимиты нужны раньше — в Итерации 1 |
| `OI-004` | Эффективный model id, который возвращает провайдер | Маркетинговое имя кандидата и фактический id могут различаться; без id `RunMetadata` невоспроизводима | Владелец проекта — решение владельца | Воспроизводимые run metadata и сравнение прогонов (ADR-004, ADR-005) | До первого реального прогона, Итерация 1 |
| `OI-005` | Ограничения DSH при работе с API провайдера | DSH — development-time инструмент; его ограничения на tooling и вызовы не проверены и не должны влиять на runtime | Владелец проекта — решение владельца | Рабочий процесс разработки и отладки, но не runtime-архитектура | До начала активной разработки адаптера, Итерация 1 |
| `OI-006` | Политика локального запуска PostgreSQL (Docker Compose против локальной службы) и backup-политика | Целевой PostgreSQL 18 + pgvector зафиксирован, но способ эксплуатации и резервное копирование не выбраны | Владелец проекта — решение владельца | Реализация хранилища, миграции и проверка восстановления (ADR-006, ADR-010) | Итерация 1, до первых миграций |
| `OI-007` | Канал human-in-the-loop для quality gate: CLI-подсказка против отдельного UI | Требование утверждения `WARNING`/`CRITICAL` есть, интерфейса и протокола прерывания нет | Владелец проекта — решение владельца | Узел quality gate и механизм interrupts (ADR-010) | Итерация 2–3, вместе с quality gate |
| `OI-008` | OCR-движки и языковые пакеты для RU/EN; потребность в GPU | Ни один движок не выбран, качество на русском и английском не измерено | Владелец проекта — решение владельца | OCR-ветка парсинга и требования к целевой машине (ADR-010) | Итерация 2, до начала OCR-работ |
| `OI-009` | Выбор embedding-модели и её revision | Кандидат `BAAI/bge-m3` из ADD §10.4 не проверен на gold-наборе; версия и `dimensions` не зафиксированы | Владелец проекта — решение владельца | RAG-индексация, формат индекса и воспроизводимость retrieval (ADR-007) | Итерация 4, до построения индекса |
| `OI-010` | Нужен ли отдельный multilingual reranker | Качество `hybrid`/`rag` без reranker-а на русско-английском корпусе не измерено | Владелец проекта — решение владельца | Сейчас ничего не блокирует; влияет на retrieval evaluation и стоимость | До retrieval evaluation, Итерация 4–6 |
| `OI-011` | Состав первого gold-набора статей | Набор из пяти статей, включая русские, английские и сложные PDF, не сформирован | Владелец проекта — решение владельца | Evaluation и стабилизация качества (ADR-009) | Итерация 6, до запуска оценки |
