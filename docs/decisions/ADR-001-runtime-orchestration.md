# ADR-001. Python и LangGraph владеют runtime, DSH — только development-time

- **Статус:** Accepted
- **Дата:** 2026-11-11
- **Связанные требования ТЗ:** разделение ответственности DSH и Python; воспроизводимый запуск
  без инструмента разработки; типизированное состояние workflow
- **Связанные разделы ADD:** §6.1, §6.2, §8.2, §8.4, §8.5

## Контекст

ADD §6.1 закрепляет разделение ролей: DSH отвечает за разработку, чтение репозитория, написание
кода по ТЗ, запуск тестов и диагностику; Python Application — за бизнес-логику, сервисы, CLI/API
и сохранение результатов. ADD §6.2 формулирует требование в неизменяемом виде: DSH не должен быть
необходим для штатной обработки документа, runtime обязан запускаться из CLI, тестового раннера
или API без активной DSH-сессии.

В репозитории это уже выполнено структурно. Единственная точка входа — `src/research_platform/cli.py`;
console script объявлен как `research-platform = "research_platform.cli:main"` в `pyproject.toml`,
поведение и коды возврата (`0` / `1` / `2`) покрыты `tests/contract/test_cli.py`, а
`tests/unit/test_import_boundaries.py::test_cli_is_the_only_entry_point_module` проверяет, что
второго `cli.py` в пакете нет. Runtime-зависимости объявлены без DSH: `pydantic==2.14.3`,
`pyyaml==6.0.3`, `langgraph==1.2.20`, `langchain-core==1.8.0`. Сам граф в Итерации 0 отсутствует:
`agents/agent_1a/graph/` содержит только README с назначением.

## Решение

1. Runtime-управление обработкой статьи принадлежит Python + LangGraph. LangGraph отвечает за
   порядок узлов, state transitions, checkpoints, interrupts и retry routing (ADD §6.1), но не за
   извлечение научных фактов.
2. DSH — development-time tool. Ни один модуль `src/research_platform` не импортирует DSH, не
   читает его конфигурацию и не требует его сессии.
3. Точки входа runtime — CLI (`research-platform`), тестовый раннер и позднее FastAPI; все они
   вызывают один и тот же application layer, а не дублируют логику.
4. Контракт состояния `agents/agent_1a/contracts/graph_state.py` — граница между процессом и
   данными: состояние хранит логические ссылки `artifact://…`, статусы и счётчики, но не payload'ы.
   `validate_state()` отвергает ключи с фрагментами `pdf`, `bytes`, `blob`, `embeddings`, `vectors`,
   значения `bytes` и строки длиннее `MAX_INLINE_STATE_STRING` (100 000 символов).

## Статус

Accepted. Решение действует для Итерации 0 и пересматривается только новым ADR. Основание для
статуса: CLI работает без DSH, ни одна runtime-зависимость не тянет DSH, граф объявлен, но не
реализован — то есть архитектурное разделение зафиксировано раньше, чем появилась возможность его
нарушить.

## Последствия

Положительные: запуск воспроизводим из CLI, pytest и будущего API одинаково; DSH можно обновить
или заменить, не затрагивая runtime; компактное JSON-сериализуемое состояние делает checkpoints и
resume дешёвыми (ADD §8.4).

Цена: отладка workflow требует локального запуска и трассировки, «удобные» возможности DSH в runtime
недоступны; `Agent1AState` — `TypedDict`, а не Pydantic-модель, поэтому инварианты проверяются
явным вызовом `validate_state()`, а не при каждой записи; checkpointing, `interrupt` и
human-in-the-loop в Итерации 0 не реализованы (значение `processing_status="waiting_for_human"`
только зарезервировано).

## Альтернативы

- **DSH как runtime-оркестратор.** Отклонено: ADD §6.2 прямо запрещает зависимость штатной
  обработки от DSH; теряются воспроизводимость и аудит, запуск из API/CI становится невозможен.
- **Внешний оркестратор (n8n, Airflow, очереди).** Отклонено на этом этапе: противоречит modular
  monolith (ADR-002) и добавляет инфраструктуру без измеренной потребности (ADD §20.3).
- **Собственная state machine без LangGraph.** Отклонено: LangGraph уже даёт checkpoints, interrupts
  и retry routing; собственная реализация повторила бы их хуже.

## Открытые риски

1. `tests/unit/test_import_boundaries.py` не запрещает импорт DSH: список запрещённых префиксов
   покрывает `langchain`, `langgraph`, `langchain_core`, `sqlalchemy`, `docling`, `pymupdf`, `openai`,
   `anthropic`, но не DSH. Первый импорт DSH в runtime пройдёт незамеченным — префикс нужно добавить
   в тест. Владелец: архитектор, Итерация 1.
2. Совместимость LangGraph 1.2.20 с checkpoint-хранилищем не проверена: checkpointer не подключён,
   выбор SQLite/PostgreSQL отложен (ADR-010).
3. 17 узлов графа ADD §8.2 не реализованы и не проверены на реальных статьях; стоимость узла и
   поведение при таймауте неизвестны.
